# Docker Manager Apps

Docker Manager Go 应用商店的应用图标与应用数据。

结构对齐 1Panel appstore:

```
apps/
  <key>/
    logo.png   # 应用图标
```

图标来源:1Panel 官方 appstore 仓库(https://github.com/1Panel-dev/appstore)。

面板通过 jsDelivr CDN 拉取:`https://cdn.jsdelivr.net/gh/MinimaxFlora/docker-manager-apps@main/apps/<key>/logo.png`
